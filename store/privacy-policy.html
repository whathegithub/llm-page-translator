LLM Page Translator 隐私政策

生效日期：2026 年 9 月 16 日

LLM Page Translator（“本扩展”）是一个浏览器扩展，用于把网页文本或用户输入的短文本发送到用户自行配置的大模型接口，并把翻译结果写回页面或显示在弹窗中。本政策说明本扩展如何处理数据。

1. 开发者不运营后台服务

本扩展没有开发者运营的服务器、账号系统或分析服务。开发者不会接收、存储或出售你的网页内容、翻译结果或 API Key。

2. 保存在本地的数据

以下数据仅保存在你的 Chrome 配置中（chrome.storage.local），不会同步到开发者：

  • 接口协议、API 地址、模型名称、源语言、目标语言和性能参数
  • 你填写的 API Key
  • 用于减少重复请求的本地翻译缓存

卸载扩展或在浏览器中清除该扩展数据后，上述本地数据会被删除。

3. 翻译时发送的数据

只有在你主动点击“翻译当前页面”“翻译输入内容”或“测试连接”后，本扩展才会发送数据。发送对象是你配置的模型服务，而不是开发者。

  • 翻译网页时：当前标签页中被选中的可见文本片段
  • 主动翻译时：你在弹窗中输入的不超过 50 个单词的文本
  • 测试连接时：一条固定的极小测试文本
  • 请求头中可能包含你提供的 API Key，用于该模型服务鉴权

网页文本可能碰巧包含姓名、账号或其他个人信息。请不要在含有敏感信息的页面上启动翻译。

4. 第三方服务

本扩展支持用户配置 OpenAI 兼容接口、DeepSeek、Anthropic 和 Google Gemini 等服务。这些服务如何处理你的数据，以对应服务商的隐私政策为准。本扩展只会在你授权后，向该 API 地址对应的源请求访问权限。

5. 权限

  • storage：保存设置和本地翻译缓存
  • activeTab：仅在你点击扩展后访问当前标签页
  • scripting：仅在你点击“翻译当前页面”后，向当前标签页注入内容脚本
  • optional host permissions：仅为你填写的 API 域名申请访问权限，不会预先申请访问所有网站

6. 远程代码

本扩展不加载、不执行远程 JavaScript。模型接口仅返回翻译文本或 JSON 数据，这些数据会作为普通文本写入页面或弹窗，不会当作代码执行。

7. 数据用途限制

本扩展收集或传输的数据只用于提供网页翻译和短文本翻译这一功能，包括请求模型、显示结果、缓存重复翻译，以及连接测试。开发者不会将数据用于广告、信用评估或其他无关用途。

8. 儿童

本扩展不以儿童为对象，也不会故意收集儿童的个人信息。

9. 政策更新

若数据处理方式发生变化，我们会更新本页面并调整扩展版本说明。继续使用更新后的扩展，即表示你了解更新后的政策。

Privacy Policy

Effective date: September 16, 2026

LLM Page Translator (“the extension”) sends webpage text or short text you enter to an LLM API that you configure, then writes translations back into the page or shows them in the popup. This policy describes how the extension handles data.

The developer does not operate a backend, account system, or analytics service, and does not receive, store, or sell your page content, translations, or API keys.

Settings, API keys, and a local translation cache are stored only in chrome.storage.local on your computer. Text is sent to your configured model provider only after you click Translate, Translate input, or Test connection. The extension does not execute remote code. Optional host permissions are requested only for the API origin you enter.

Do not start translation on pages that contain sensitive information. Third-party model providers process data according to their own policies.
